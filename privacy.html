Règles de confidentialité

Dernière mise à jour : 24 novembre 2026

Privacy policy. Last updated: November 24, 2026.

Données utilisées

Factory App utilise l’API YouTube Data et l’API YouTube Analytics, uniquement sur la chaîne YouTube de son propriétaire (« Maths Anticipées »). Aucune autre chaîne ni aucun autre utilisateur n’est concerné.

The app uses the YouTube Data API and YouTube Analytics API only on the owner’s own channel.

Stockage

Le jeton d’accès OAuth est stocké localement, sur l’ordinateur du propriétaire. Il n’est envoyé à aucun serveur autre que ceux de Google.

The OAuth token is stored locally on the owner’s computer and is sent only to Google’s servers.

Partage

Factory App ne collecte, ne vend et ne partage aucune donnée personnelle avec des tiers.

The app does not collect, sell or share any personal data with third parties.

Règles d’utilisation des données Google

L’utilisation par Factory App des informations reçues des API Google respecte les Règles relatives aux données utilisateur des services d’API Google (Google API Services User Data Policy), y compris les exigences d’utilisation limitée (Limited Use).

Factory App’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Révoquer l’accès

L’accès peut être révoqué à tout moment sur https://myaccount.google.com/permissions.

Access can be revoked at any time at https://myaccount.google.com/permissions.
